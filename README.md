# 持倉羅盤 | Portfolio Compass

**看懂配置，讓每一步更有方向。**

一個免費、開源、本機優先的投資組合儀表板。比較目前與目標配置、檢視再平衡差距，並把自己的資料備份在自己選擇的位置。

## 隱私設計

- 持倉、成本、數量、現金和每日資產紀錄只儲存在使用者目前瀏覽器的 `localStorage`。
- 不含登入、雲端資料庫、同步服務、廣告、追蹤分析或行情 API 請求。公開託管只提供靜態網頁；應用程式不會把投資資料傳回主機。
- JSON 備份未加密，可能包含完整財務資料。請將檔案保存在安全位置，勿放到公開連結、issue 或聊天中。
- 網站主機仍可能依其政策記錄一般連線資訊（例如 IP、時間和請求路徑）；這些網站存取紀錄不含應用程式內的持倉內容。

## 功能

- 台灣上市／上櫃、美股、日股與 TWD、USD、JPY 現金配置
- 目前配置與目標配置圓餅圖、未配置比例、再平衡差距分組與建議整股數
- 手動輸入現價、平均成本、數量和長期目標價
- 本機每日資產紀錄與長期趨勢
- 匯出／匯入 JSON 備份；匯入前會驗證資料並確認覆寫
- 桌機與手機響應式版面

## 開始使用

不需建立帳戶或設定 API key。

```bash
npm install
npm run dev
```

在 `http://127.0.0.1:5173` 開啟網頁。持倉資料留在目前瀏覽器；換裝置時請從舊裝置匯出 JSON，再在新裝置匯入。

## 部署

此專案是純靜態 Vite 網站，可部署到 Vercel、Cloudflare Pages 或任何支援靜態網站的主機。建置命令為 `npm run build`，輸出資料夾為 `dist`。若連結 GitHub，推送至主分支即可觸發自動部署。

## 開發檢查

```bash
npm test
npm run build
```

## 使用限制

此工具用於整理持倉與試算配置差距，不提供即時行情、交易執行、個人化投資建議或報酬保證。請自行核對價格、匯率、交易單位及券商費用。歷史趨勢從資料可用且網頁開啟時開始記錄，不會回填過去資料。

另請閱讀[隱私與資料說明](./privacy.html)。
