← 回到持倉羅盤

隱私與資料說明

持倉羅盤是本機優先的投資組合整理工具。你可以在公開網站上使用它，但應用程式不需要帳戶，也沒有雲端同步或行情 API。

應用程式資料存放位置

持倉代號、名稱、數量、平均成本、目標配置、手動現價與每日資產紀錄，存放在你目前瀏覽器此網站來源的本機儲存區。網站程式不會把這些資料傳送到伺服器或第三方服務。清除瀏覽器網站資料會一併刪除這些資料。

備份檔案

JSON 匯出檔可能包含你的完整持倉、成本、現金、報價與每日資產歷史，且不會加密。自行選擇安全的位置保存。不要把備份上傳到公開 GitHub repository、公開雲端連結或公開討論區。匯入只會在你確認後覆寫目前瀏覽器的本機資料。

網站主機紀錄

主機服務可能依其服務條款記錄一般網站連線資訊，例如 IP 位址、請求時間和請求路徑。這些主機層級的存取紀錄與應用程式內的投資資料分開；本網站不加入廣告、追蹤分析或第三方腳本。

你的選擇

你可以在 App 匯出備份、刪除本機資料或清除瀏覽器網站資料。換裝置時，請自行透過安全管道轉移 JSON 備份。

用途限制

本工具僅協助整理和試算投資組合，不構成投資建議、交易指示或績效保證。你需自行確認輸入、行情、匯率、交易單位與費用。
